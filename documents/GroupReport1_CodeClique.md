## 1. Iteration 1 - Summary

Student user stories: 

1. As a student, I want to create an account and maintain a profile with some key information, such as major, research interests, experience, and contact information. --> Vanya

2. As a student, I want to log in to my account with my WPI credentials and state my research interests and programming experience --> Vanya

3. As a student, I want to be able to edit my profile --> Pranav,  Vanya

4. As a student, I want to be able to add and remove advanced courses I have taken to my profile --> Vanya

5. As a student, I want to be able to browse through all available research positions and view some basic information (faculty member, position title) about each position so that I can get a good overview of my options. --> Pranav

6. As a student, I want to be able to view specific details about a position in which I’m interested. --> Pranav

Faculty user stories:

1. As a faculty member, I want to activate my account via email verification so that I can store my data with minimal effort --> Ritvik

2. As a faculty member, I want to log in to my account with my WPI credentials or using SSO so that I can securely access my data. --> Ritvik

3. As a faculty member, I want to create undergraduate research positions so that I can specify what I am looking for and provide the information necessary to only get qualified applicants. --> Elliot, Vanya

4. As a faculty member, I want to be able to edit my profile so that I can see my account information and approve or reject recommendation requests. --> Elliot, Ritvik

4. As a faculty member, I want to view my own profile so that I can see my account information and approve or reject recommendation requests. --> Elliot, Ritvik

5. As a faculty member, I want to be able to edit pre-existing lists (Programming Languages, Research Topics) in order to match the needs of positions I have/will post. --> Elliot, Ritvik
